Project: The Page Hive

The Page Hive is a web application that allows users to create an account, borrow available books and return them to their virtual shelves. The app integrates an external API to dynamically generate a wide range of books and uses MongoDB to store and track borrowed books. 

Tech used: 
EJS, CSS, JavaScript, Node JS, Express, and MongoDB



Lessons Learned:

While building Page Hive, I gained hands-on experience with full-stack development, including fetching APIs, handling asynchronous data fetching, and managing a MongoDB database.
